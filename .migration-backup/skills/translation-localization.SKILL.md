# Translation & Localization Skill

## Purpose
Automate management and synchronization of i18n message files and translations for the yoyomap project.

## Features
- Extract untranslated strings
- Suggest and sync translations across languages
- Generate translation tasks and reports

## Usage
- Input: Source code, message files
- Output: Updated i18n files, translation checklists

## Integration
- Google Translate API, Notion, Google Sheets

# Location Data Management Skill

## Purpose
Automate importing, deduplication, normalization, and enrichment of city/region/country/location data for the yoyomap project.

## Features
- Import/export location data (CSV, Excel, Google Sheets)
- Deduplicate and normalize entries
- Geocode and generate slugs
- Validate and enrich location records

## Usage
- Input: Raw location data, spreadsheets
- Output: Cleaned, enriched, and exportable location datasets

## Integration
- Google Sheets, CSV, Excel, geocoding APIs

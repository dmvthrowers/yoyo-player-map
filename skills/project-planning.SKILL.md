# Project Planning & Timeline Skill

## Purpose
Automate project plan creation, timeline management, and deadline tracking for club and event projects.

## Features
- Generate project plans and Gantt charts
- Track milestones, deadlines, and dependencies
- Send reminders for upcoming tasks
- Export plans to Google Sheets/Excel

## Usage
- Input: Project goals, deadlines, dependencies
- Output: Timeline, checklist, reminders

## Integration
- Google Sheets, Zapier, Monday.com

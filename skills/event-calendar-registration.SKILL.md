# Event Calendar & Registration Skill

## Purpose
Automate event calendar management and registration workflows.

## Features
- Manage event calendars and sync with Google Calendar
- Integrate with Ticket Tailor/Airtable for registration
- Track attendee lists and send reminders

## Usage
- Input: Event details, registration data
- Output: Calendar events, attendee lists, reminders

## Integration
- Google Calendar, Ticket Tailor, Airtable

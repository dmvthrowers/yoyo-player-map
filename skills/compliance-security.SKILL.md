# Compliance & Security Skill

## Purpose
Automate compliance checks, repo audits, and legal document tracking.

## Features
- Audit repos for secrets and compliance gaps
- Track legal documents (privacy, waiver, refund policy)
- Generate compliance checklists and reports

## Usage
- Input: Repo URL, policy requirements
- Output: Audit reports, compliance status

## Integration
- GitHub, Google Drive, Notion

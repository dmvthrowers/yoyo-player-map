# Secretary/Clerk Automation Skill

## Purpose
Automate repetitive admin tasks and support event/club operations.

## Features
- Automate calendar invites, email responses, document formatting
- Generate meeting minutes and action items
- Manage document templates and filing

## Usage
- Input: Meeting details, emails, docs
- Output: Calendar events, formatted docs, minutes

## Integration
- Google Calendar, Gmail, Docs, Outlook

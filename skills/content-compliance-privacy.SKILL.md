# Content Compliance & Privacy Skill

## Purpose

Scan entries for PII, inappropriate content, and missing consents in the yoyomap project.

## Features

- Scan for PII and inappropriate content
- Check for missing privacy/terms consents
- Automate compliance checks and flag issues

## Usage

- Input: Entry data, consent fields
- Output: Compliance reports, flagged entries

## Integration

- Admin dashboard, compliance APIs

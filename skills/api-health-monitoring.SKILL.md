# API Health & Rate Limit Monitoring Skill

## Purpose

Monitor API endpoints for errors, latency, and rate limit status in the yoyomap project.

## Features

- Monitor endpoint health and latency
- Alert on failures or quota issues
- Generate usage and error reports

## Usage

- Input: API endpoint URLs, thresholds
- Output: Health dashboards, alerts, reports

## Integration

- Email, Slack, monitoring dashboards

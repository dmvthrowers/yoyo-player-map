# Art & Branding Skill

## Purpose
Automate logo, banner, and flyer generation and manage design assets.

## Features
- Generate and update logos, banners, flyers (Canva, Playwright, SVG)
- Maintain design asset library and version history

## Usage
- Input: Design requirements, branding guidelines
- Output: Art assets, export files

## Integration
- Canva, Playwright, Google Drive

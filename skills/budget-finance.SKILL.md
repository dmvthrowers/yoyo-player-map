# Budget & Finance Skill

## Purpose
Automate budget creation, expense tracking, and sponsor/vendor invoice management.

## Features
- Build and update budget spreadsheets
- Track expenses and income
- Generate invoices for sponsors/vendors
- Integrate with Google Sheets and Zapier

## Usage
- Input: Budget categories, transactions
- Output: Budget summary, alerts, invoices

## Integration
- Google Sheets, Zapier, PayPal, Venmo

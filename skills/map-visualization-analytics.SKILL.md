# Map Visualization & Analytics Skill

## Purpose

Generate map visualizations and analytics for player, shop, and club data in the yoyomap project.

## Features

- Create heatmaps and cluster maps
- Export analytics for reporting or social sharing
- Visualize player/shop/club density

## Usage

- Input: Location datasets
- Output: Map images, analytics reports

## Integration

- Google Maps API, Mapbox, Playwright

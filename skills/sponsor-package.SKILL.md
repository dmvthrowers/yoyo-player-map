# Sponsor Package & Outreach Skill

## Purpose
Automate sponsor package creation, outreach tracking, and follow-up management.

## Features
- Generate sponsor packages (PDF/HTML/Markdown)
- Track outreach status and automate follow-ups
- Manage sponsor data and agreements

## Usage
- Input: Sponsor tiers, benefits, contacts
- Output: Packages, outreach log, reminders

## Integration
- Jotform, Google Sheets, MailerLite

# User Feedback & Issue Triage Skill

## Purpose
Aggregate, summarize, and prioritize user feedback and issues for the yoyomap project.

## Features
- Aggregate feedback from forms and emails
- Summarize, tag, and prioritize issues
- Generate actionable reports for the dev team

## Usage
- Input: Feedback submissions, emails
- Output: Issue summaries, priority lists, reports

## Integration
- Google Forms, Gmail, Notion, GitHub Issues

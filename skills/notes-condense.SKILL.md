# Notes & Knowledge Condenser Skill

## Purpose
Summarize and organize notes from previous events, meetings, and communications.

## Features
- Summarize notes and meeting minutes
- Organize/tag knowledge for easy retrieval
- Generate action items and follow-ups

## Usage
- Input: Raw notes, transcripts, docs
- Output: Summaries, action lists, knowledge base

## Integration
- Google Docs, Notion, Monday.com

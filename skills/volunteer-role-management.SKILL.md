# Volunteer & Role Management Skill

## Purpose
Automate volunteer list creation, role assignment, and onboarding for events.

## Features
- Build volunteer lists and assign roles
- Track confirmations and availability
- Generate role descriptions and onboarding checklists

## Usage
- Input: Volunteer names, roles, availability
- Output: Role matrix, onboarding docs

## Integration
- Google Sheets, Monday.com

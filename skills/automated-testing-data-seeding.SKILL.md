# Automated Testing & Data Seeding Skill

## Purpose
Automate testing and data seeding for API endpoints and UI flows in the yoyomap project.

## Features
- Generate and run tests for APIs and UI
- Automate seeding of test data for dev/staging
- Validate data integrity and flows

## Usage
- Input: Test cases, seed data
- Output: Test results, seeded environments

## Integration
- Jest, Playwright, custom scripts

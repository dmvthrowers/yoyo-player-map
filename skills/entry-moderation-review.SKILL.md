# Entry Moderation & Review Skill

## Purpose

Automate review and moderation of new player, shop, and club submissions in the yoyomap project.

## Features

- Review queue automation for new entries
- Moderation checklists and approval workflows
- Duplicate detection and flagging

## Usage

- Input: New submissions, moderation rules
- Output: Moderation queue, flagged entries, approval status

## Integration

- Admin dashboard, email notifications
